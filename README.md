# Holiday Checklist

Web app for entering packing items and tasks to do before a holiday so you don't forget anything.

A lightweight static HTML app for creating and tracking packing items and pre-travel tasks. Designed to be simple and easy to use—open in any browser, add items, check them off, and plan your trip-prep quickly.

## Features

- Add, edit, and remove packing items and tasks
- Mark items/tasks as completed
- Simple, mobile-friendly interface
- Works offline in the browser (depending on how you host it)

## Usage

1. Clone or download this repository.

   git clone https://github.com/mikecimelli/holiday-checklist.git

2. Open `index.html` in your browser.

   - On desktop: double-click `index.html` or open it from your browser's File > Open menu.
   - To serve locally with a simple HTTP server (recommended for some browsers):
     - Python 3: `python -m http.server 8000` then visit `http://localhost:8000`
     - Node (http-server): `npx http-server` then visit `http://localhost:8080`

3. Add items and tasks using the UI and check them off as you prepare for your holiday.

## Development

This project is primarily HTML with a small amount of JavaScript.

- Edit the HTML files and assets in this repo to modify UI text, structure, and styles.
- If JavaScript behavior needs updating, edit the script files and test in a browser.

## Deployment

- GitHub Pages: Enable Pages in the repository settings and set the branch to `main` (or the repository's default branch) and the folder to `/ (root)` to host the site.
- Any static site hosting (Netlify, Vercel, Surge) will also work.
